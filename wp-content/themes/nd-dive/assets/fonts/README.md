# Fonts

Self-hosted from Google Fonts (latin subset, variable-weight `.woff2`), loaded by the `@font-face` rules at the top of `style.css`.

| File | Font | Weights | Licence |
|---|---|---|---|
| `inter-latin.woff2` | Inter, © The Inter Project Authors | 400–700 | SIL Open Font License 1.1 |
| `jetbrains-mono-latin.woff2` | JetBrains Mono, © The JetBrains Mono Project Authors | 400–500 | SIL Open Font License 1.1 |

Licence text: https://openfontlicense.org. Only latin characters are included; text in other scripts falls back to the system font.
